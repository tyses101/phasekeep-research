S31 run history (author-side; all runs by the same author that wrote the script)

First run: crashed (KeyError: the dictionary of mechanisms lacked the Z3 variant that S30's round-trip builder expects).  Fixed.
Second run: crashed in the break-even solver (an array compared as a scalar: the heralded-loss array was compared with the threshold without indexing the wait).  Fixed.
Third run: ALL PASS.  Before recording I read the output and the code and added, none of which changed an earlier number:
  - the adaptive gain over the BEST SINGLE FIXED option (the quantity the question is about; the first version printed coverage of each option and of the oracle but not the difference), because comparing the oracle with STAY alone overstates the benefit: the best fixed option is M5 (always hand off to a second register)
    in the envelope, and the oracle's gain over it is +2.1, 0.0 and +6.2 percentage points for the three requirements at s = 1;
  - a sanity print that STAY and CONV change with the bias (STAY 1.5e-2 unbiased, 3.9e-2 at b = 100 at p = 1e-3, rho_p = 1, w = 100) so that the identical coverage counts for the two biases are not mistaken for a bug (they are a property of the coarse grid);
  - an independent plain-loop recount of every coverage number (the first aggregator used numpy any/and; the recount is identical), replacing a K2b condition that would have been true by construction (adaptive coverage is at least any fixed coverage);
  - a K4 check that records that the decision is sensitive in both directions; its counts are printed above it.
Things this script does not check and that a reader should not assume: that an estimate of p, rho_p and the wait is available (the oracle is an upper bound); that the requirement levels (1e-3, 1e-2, 1e-4 with loss caps 0.10, 0.30) are meaningful (illustrative); that the heralded failure of a data-touching gate destroys the information (V1.0's reading, S07);
that the quieter memory f_m = 0.1 exists.  The whole adaptive-handoff benefit is attributable to that last assumption: at f_m = 1 the invariant check K2a finds no condition where the handoff to a second register of the same code meets a requirement that staying fails.
Independent evidence in this script: K0b (the memory of every round trip by circuit simulation of all Pauli patterns against the closed-form code-theoretic probabilities, difference 4e-14), K1 (the in-place conversions by stabilizer expectation values), K2b (recount), K3 (each solved kappa* is checked by evaluating just below and just above it).
Not independent: the fault model, the idle model and S30's coefficients are shared with the earlier scripts.
Final run: ALL PASS (see execution-record.txt).
